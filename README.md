## Описание предметной области — Шифр Хилла

**Шифр Хилла** — симметричный шифр, основанный на линейной алгебре. Открытый текст разбивается на блоки (биграммы или триграммы), каждый блок представляется вектором и умножается на ключевую матрицу по модулю размера алфавита.

### Метод шифрования

- Текст разбивается на блоки по **2 или 3 символа** (биграммы / триграммы).
- Каждый блок представляется числовым вектором.
- Шифрование: **C = K · P (mod n)**, где K — ключевая матрица, P — вектор открытого текста.
- Дешифрование: **P = K⁻¹ · C (mod n)**, где K⁻¹ — обратная матрица по модулю n.

### Требования к ключевой матрице

- Размерность: **2×2** или **3×3**.
- Матрица должна быть **обратимой** по модулю размера алфавита.
- **Определитель (det)** матрицы должен быть ненулевым и взаимно простым с модулем n.

### Обрабатываемые исключительные ситуации

- `null` или пустая строка на входе.
- Вырожденная матрица (det = 0 или gcd(det, n) ≠ 1).
- Неверный размер матрицы.
- Некорректные символы входного текста.

## Диаграмма вариантов использования

Диаграмма хранится в файле `Диаграмма вариантов использования.drawio` в корне репозитория.

Основные варианты использования:
- **Задать пример** — пользователь вводит открытый или зашифрованный текст.
- **Загрузить ключевую матрицу** — пользователь задаёт матрицу 2×2 или 3×3.
- **Шифровать** — система выполняет шифрование шифром Хилла.
- **Дешифровать** — система выполняет дешифрование шифром Хилла.
- **Проверить обратимость** — система проверяет корректность всех полей.
- **Посмотреть статус** — отображение сообщений при вырожденной матрице, пустом вводе и т.д.

## Применяемые средства отладки Visual Studio

В ходе выполнения практической работы применялись следующие встроенные средства отладки Microsoft Visual Studio:

| Средство | Описание |
|---|---|
| **Точки останова (Breakpoints)** | Приостановка выполнения в заданных строках кода для пошагового анализа |
| **Пошаговое выполнение (Step Over / Step Into / Step Out)** | Выполнение кода по одной инструкции для отслеживания логики |
| **Окно вывода** | Просмотр диагностических сообщений и вывода Debug.WriteLine() |
| **Окно стека вызовов** | позволяет просмотреть, какие методы были вызваны. |
| **Окно интерпритации** | позволяет записывать и выражения во время отладки. |
| **Окно просмотра** | позволяет отслеживать выбранные переменные и выражения с течением времени при отладке. |
